# Портфолио — Денис Цуранов

Статичный сайт-портфолио с рубрикатором (фильтрация работ по разделам), тёмная минималистичная тема.

## Как открыть

В папке проекта выполни:

```
py server.py
```

(или `python server.py`). Скрипт поднимет локальный сервер и сам откроет браузер на
`http://localhost:8765`. Остановить — `Ctrl+C`.

Другой порт: `py server.py 9000`.

## Структура

| Файл | Назначение |
|------|------------|
| `index.html` | разметка страницы |
| `styles.css` | стили / тема |
| `script.js` | рубрикатор, сетка, лайтбокс |
| `data.js` | **список всех работ** (сгенерирован) |
| `gen_data.py` | генератор `data.js` из папок с файлами |
| `make_posters.py` | генератор постеров (кадров) для видео → `posters/` (нужен ffmpeg) |
| `posters/` | превью-кадры видео (сгенерированы) |

## Рубрики

- **Все**
- Реклама → HYPER · HYPER·ИИ · Соцсети · Имиджевые · Типовые
- Спортивные мероприятия → Спорт

## Как добавить / обновить работы

1. Положи новые файлы в нужную папку внутри `Реклама/...` или `Спортивные Меропртия`.
2. Если добавлял **видео** — сначала сделай для них постеры:
   ```
   py make_posters.py
   ```
3. Перегенерируй список работ:
   ```
   py gen_data.py
   ```
4. Обнови страницу в браузере.

Чтобы добавить **новую рубрику** — допиши папку в `FOLDER_MAP` в `gen_data.py`.

## Структура страницы

Сайт — **одна страница** (`index.html`). В левом сайдбаре: имя, роль, блок «опыт»
(FoxMotion Studio, DADA Creative) и контакты (Telegram, email). Справа — рубрикатор и
сетка работ. Контакты правятся прямо в сайдбаре `index.html`.

## Заметки

- Видео `.mov` (`INTRO_1_SIDE_SCREEN_CSKA_W_AUDIO.mov`, `LOGO_+_BG_STRIPE.mov`) могут не
  воспроизводиться в Chrome/Firefox. Для веба лучше пересохранить их в `.mp4` (H.264).
- Несколько видео очень тяжёлые (`preview_RASA_v3.mp4` ~1 ГБ, `intro_2.mp4` ~100 МБ).
  Они грузятся только при открытии. Для публикации в интернете их стоит сжать.
